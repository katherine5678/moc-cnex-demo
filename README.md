# 兩岸交流紀錄（純前端）

純前端網站，用於建檔、查詢、編輯與統計兩岸交流案件。資料存在瀏覽器 `localStorage`，無需後端。

## 功能

- **CRUD**：團號、邀請單位、收件號、申請人姓名、交流人員清單
- **貼上通知信**：複製移民署自動通知信文字，一鍵解析欄位
- **匯入 PDF**：上傳「團體名冊」（附件 2 格式）帶入交流人員
- **統計**：案件數、人數、邀請單位、月份分布
- **匯出／匯入 JSON**：備份或搬移資料

## 使用方式

需以本機 HTTP 伺服器開啟（ES modules 無法直接用 `file://`）：

```bash
# Python
python3 -m http.server 5173

# 或 Node
npx --yes serve -p 5173
```

瀏覽器開啟：http://localhost:5173

## 通知信解析範例

可貼上類似內容：

```
申請事由『204』， 團號:155997357,邀請單位『威信國際行銷有限公司』，
(收件號:115660546990【姓名：楊亦嘉】共1人) 已於 2026/06/19加入您的線上資格審新進案件中。
```

## 團體名冊 PDF

欄位對應附件 2：編號、姓名、性別、現任職單位、職稱。

## 網址（可分享）

使用 hash 路由，複製網址即可分享／重新開啟同一頁：

| 頁面 | 網址 |
|------|------|
| 首頁（統計＋案件表） | `#/records`、`#/records/2026`、`#/records/all` |
| 邀請單位 | `#/unit/單位名稱` |
| 案件詳情 | `#/case/團號` |

## 部署（Cloudflare Worker Static Assets）

```bash
npx wrangler deploy
```

設定見根目錄 `wrangler.toml`。Worker 名稱預設為 `moc-cnex-demo`，若與 Dashboard 不同請改 `name`。
